# PMH Scrollytelling – Digitaler Output

Static web presentation for **Julian Meyer**, Ethics Lab, Universität Bonn.

## View the site

Open the published GitHub Pages URL or open `index.html` locally in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `pmh-scrollytelling`) under your GitHub organization.
2. Upload the **contents** of this folder to the repository root (not the `.zip` file itself).
3. In **Settings → Pages**, set **Source** to **Deploy from a branch**, **Branch** to **main**, and folder to **/(root)**, then save.
4. Open `https://YOUR-ORGANIZATION.github.io/pmh-scrollytelling/` after GitHub Pages deploys.

The entry point is `index.html`, which links to `01_PMH_Scrollytelling_Offline.html` and the copyright PDF.

All core styles and JavaScript are bundled in the interactive HTML file. The external Deezer source link requires an internet connection. The interactive piano uses the browser's audio output.
